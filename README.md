<h1 align="center"> Sistem Penjadwalan Meruap </h1>
<p align="center">
</p>

<p align="left">Sistem ini dibuat dalam rangka mengotomatisasi proses penjadwalan dan pemantauan scheudling atas karyawan - karyawan BWP Meruap</p>

<h2 align="left"> Environment Set Up </h2>
<h3 align="left"><b> Node Js </b></h3>
<p align="left">Memastikan bahwa Node.js telah terinstal, cek dengan "node -v" & "npm -v"</p>
<p align="left">Instalasi:</p>
<p align="left">Windows: winget install OpenJS.NodeJS.LTS</p>
<p align="left">MacOS: brew install node</p>

<h3 align="left"><b>.NET SDK </b></h3>
<p align="left">Memastikan bahwa .NET SDK telah terinstal, cek dengan "dotnet --version"</p>
<p align="left">Instalasi:</p>
<p align="left">Windows: winget install Microsoft.DotNet.SDK.9</p>
<p align="left">MacOS: brew install --cask dotnet-sdk</p>

<h3 align="left"><b> Microsoft SQL Server Express Edition</b></h3>
<p align="left">Memastikan bahwa SQL Server berjalan dan terinstall"</p>
<p align="left">Instalasi: https://www.microsoft.com/sql-server/sql-server-downloads</p>

<h2 align="left"> Cara Run </h2>
<p align="left">Terminal 1: "cd backend" lalu "dotnet run"</p>
<p align="left">Terminal 2: "cd frontend" lalu "npm run dev"</p>
